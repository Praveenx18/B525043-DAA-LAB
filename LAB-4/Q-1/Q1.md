# Stable Sorting by Colour

## Problem

Given `n` pairs `(number, colour)` where the input is already sorted by number, sort the pairs as:

**Red → Blue → Yellow**

while keeping the numbers of identical colours sorted.

## Pseudo Code

Make a structure taking number and color as members
Make a function to sort the colors taking structure and its size as parameters
Inside the function make 3 structurres for red , blue and yellow 
run a loop from 0 to n if it 

## Approach

Use three arrays: `Red`, `Blue`, and `Yellow`.

Traverse the input once and place each item into its corresponding array. Since the input is processed from left to right, the order of numbers within each colour is preserved.

Finally, combine the three arrays:

`Red → Blue → Yellow`

## Example

### Input
2 R  
5 B  
7 R  
10 Y  
12 B  
15 Y  
18 R  

### Output
2 R  
7 R  
18 R  
5 B  
12 B  
10 Y  
15 Y  

## Complexity

- Time Complexity: **O(n)**
- Space Complexity: **O(n)**
- Comparisons: **n ≤ C ≤ 2n**, therefore **O(n)**

## Validation

The C program measures:

- Number of colour comparisons
- Execution time

The results can be used to validate the expected **O(n)** time complexity.
