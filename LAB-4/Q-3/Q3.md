# K-Element Sum

## Problem

Given a set `S` of `n` integers and an integer `T`, determine whether `k` elements of `S` add up to `T`.

## Approach

1. Sort the set `S` using `qsort()`.
2. Recursively generate every combination of `k - 1` elements.
3. Calculate the sum of the selected `k - 1` elements.
4. Compute the required element as `T - sum`.
5. Use binary search to check whether the required element exists in `S`.
6. If found, a valid combination exists.

## Complexity

The number of combinations of `k - 1` elements is:

`O(n^(k-1))`

Binary search takes:

`O(log n)`

Therefore:

- Time Complexity: **O(n^(k-1) log n)**
- Space Complexity: **O(k)**

The initial sorting takes `O(n log n)`, which is dominated by the main algorithm for fixed `k >= 2`.

## Validation

The C program counts comparisons and measures execution time for different input sizes.

The results can be used to validate the theoretical complexity:

`O(n^(k-1) log n)`

For example, when `k = 3`, the complexity becomes:

`O(n^2 log n)`
