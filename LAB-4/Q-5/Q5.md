# Merge Overlapping Intervals

## Problem

Given a list of `n` intervals `(x, y)`, merge all overlapping intervals and return the resulting list.

## Approach

1. Sort the intervals by their starting point using Merge Sort.
2. Start with the first interval as the current interval.
3. Traverse the sorted intervals:
   - If the next interval overlaps with the current interval, merge them.
   - Otherwise, add the current interval to the result and start a new interval.
4. Add the final interval to the result.

## Example

Input:

`(1,3), (2,6), (8,10), (7,18)`

Output:

`(1,6), (7,18)`

## Complexity

- Sorting: **O(n log n)**
- Merging: **O(n)**
- Overall Time Complexity: **O(n log n)**
- Space Complexity: **O(n)**

## Validation

The C program counts comparisons and measures execution time for different input sizes to validate the theoretical **O(n log n)** complexity.
