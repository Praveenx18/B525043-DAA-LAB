# Pair Sum from Two Sets

## Problem

Given two sets `S1` and `S2`, each containing `n` elements, and a number `x`, determine whether there exists a pair of elements, one from each set, whose sum is equal to `x`.

## Approach

1. Sort `S2` using `qsort()`.
2. For every element `a` in `S1`, calculate `x - a`.
3. Perform binary search for `x - a` in `S2`.
4. If the element is found, a valid pair exists.

## Complexity

- Sorting: **O(n log n)**
- Binary searches: **O(n log n)**
- Overall Time Complexity: **O(n log n)**
- Space Complexity: **O(n)**

## Validation

The C program counts the number of comparisons and measures the execution time for different input sizes to validate the theoretical time complexity.
