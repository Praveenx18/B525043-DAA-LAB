# Maximum Simultaneous Party Attendance

## Problem

Given the entry time `ai` and exit time `bi` of each of `n` people, determine the time when the maximum number of people were simultaneously present at the party.

All entry and exit times are distinct.

## Approach

Represent each entry and exit as an event:

- Entry → `+1`
- Exit → `-1`

Sort all `2n` events by time using Merge Sort.

Then scan the events in chronological order:

- For an entry, increment the current count.
- For an exit, decrement the current count.
- Whenever the current count exceeds the previous maximum, store the time and count.

## Complexity

- Number of events: `2n`
- Sorting: **O(n log n)**
- Scanning: **O(n)**
- Overall Time Complexity: **O(n log n)**
- Space Complexity: **O(n)**

## Validation

The C program counts the number of comparisons and measures the execution time.

The results for increasing values of `n` can be used to validate the expected **O(n log n)** complexity.
