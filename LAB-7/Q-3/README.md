# Reve's Puzzle – 4-Peg Tower of Hanoi

## Problem Statement

There are eight disks of different sizes and four pegs. Initially, all disks are placed on the first peg in decreasing order of size, with the largest disk at the bottom and the smallest at the top.

The objective is to transfer all disks to another peg while following these rules:

1. Only one disk can be moved at a time.
2. A larger disk cannot be placed on top of a smaller disk.

The algorithm must solve the 8-disk problem in **33 moves** and should be generalized for an `n`-disk problem.

---

## Approach

This solution uses the **Frame-Stewart / Divide and Conquer approach** combined with **Dynamic Programming**.

For `n` disks, choose a value `k`:

1. Move the top `k` disks from the source peg to an auxiliary peg using four pegs.
2. Move the remaining `n-k` disks from the source to the destination using the standard three-peg Tower of Hanoi algorithm.
3. Move the `k` disks from the auxiliary peg to the destination using four pegs.

The recurrence is:

`T(n) = min(2*T(k) + 2^(n-k) - 1)`

for `1 <= k < n`.

For 8 disks, the best value is `k = 4`.

Since `T(4) = 9`:

`T(8) = 2*T(4) + 2^4 - 1`

`T(8) = 2(9) + 15 = 33`

Therefore, the puzzle can be solved in **33 moves**.

---

## Algorithm

### Dynamic Programming

For every number of disks from `1` to `n`:

1. Try every possible value of `k`.
2. Calculate `2*T(k) + 2^(n-k) - 1`.
3. Select the minimum value.
4. Store the minimum number of moves in `dp[n]`.
5. Store the corresponding `k` in `bestK[n]`.

### Puzzle Solution

The recursive function `solve4(n, source, destination, auxiliary1, auxiliary2)`:

- Returns if `n == 0`.
- Moves the disk directly if `n == 1`.
- Gets the best `k`.
- Moves `k` disks using the four-peg algorithm.
- Moves `n-k` disks using the three-peg Tower of Hanoi.
- Moves the `k` disks to the destination using the four-peg algorithm again.

## Why the Answer is 33

For 8 disks, the algorithm chooses `k = 4`.

```text
Move 4 disks using 4 pegs = 9 moves
Move remaining 4 disks using 3 pegs = 15 moves
Move 4 disks using 4 pegs = 9 moves
```

Total:

```text
9 + 15 + 9 = 33 moves
```

## Complexity Analysis

### Dynamic Programming

For each `n`, all possible values of `k` from `1` to `n-1` are tested.

The total number of comparisons is approximately:

`1 + 2 + 3 + ... + (n-1) = n(n-1)/2`

Therefore:

- **Time Complexity:** `O(n^2)`
- **Space Complexity:** `O(n)`

The `dp[]` array stores the minimum moves, and `bestK[]` stores the best split.

### Generating the Moves

If all moves are printed, the time is proportional to the number of moves generated:

`O(T(n))`

For 8 disks, `T(8) = 33`.

The recursion uses `O(n)` stack space.

## Important Functions

### `hanoiMoves(int n)`

Calculates the number of moves required for normal three-peg Tower of Hanoi:

`2^n - 1`

### `calculateDP(int n)`

Uses Dynamic Programming to calculate the minimum moves and best `k` for every number of disks.

### `moveDisk(int from, int to)`

Moves one disk and checks whether the move is legal.

### `solve3(int n, int source, int destination, int auxiliary)`

Implements the standard three-peg Tower of Hanoi recursively.

### `solve4(int n, int source, int destination, int auxiliary1, int auxiliary2)`

Implements the four-peg Reve's Puzzle recursively using the best value of `k`.

### `initialize(int n)`

Places all disks on the first peg before solving starts.

## Conclusion

The Frame-Stewart approach uses the fourth peg to reduce the number of moves compared with the standard three-peg Tower of Hanoi.

For 8 disks:

```text

Standard Tower of Hanoi = 255 moves
```

Thus, the program solves and validates the required 8-disk Reve's Puzzle in **33 moves** and provides a generalized solution for `n` disks.
