# Max and Min using Divide and Conquer

## Overview

This project implements a **Divide and Conquer algorithm** to find the **maximum and minimum elements** in an array.

The algorithm recursively divides the array into smaller subarrays, finds the maximum and minimum of each subarray, and combines the results.

The objective is to ensure that the number of comparisons is bounded by approximately **3n/2**.

## Problem Statement

Using the Divide and Conquer approach, develop an algorithm to find the maximum and minimum elements in an array of size `n` such that the number of comparisons is bounded by:

```text id="w1t8o9"
3n/2
```

The algorithm is implemented in C and experimentally validated for different input sizes.

## Approach

The array is divided into two halves recursively.

For each subarray:

1. If there is one element, it is both the minimum and maximum.
2. If there are two elements, only one comparison is required to determine the minimum and maximum.
3. Otherwise, divide the array into two halves.
4. Recursively find the minimum and maximum of both halves.
5. Compare the two maximum values.
6. Compare the two minimum values.
7. Return the overall minimum and maximum.

## Operations Implemented

The following operations are implemented:

* Divide the array into two halves
* Find minimum recursively
* Find maximum recursively
* Combine results from both halves
* Count/Analyze element comparisons

## Time Complexity

The recurrence relation for the Divide and Conquer approach is:

```text id="3cq6f8"
T(n) = 2T(n/2) + 2
```

Therefore, the time complexity is:

```text id="7yys2q"
O(n)
```

The algorithm visits every element while performing a limited number of comparisons.

## Comparison Bound

For an even number of elements, the Divide and Conquer approach requires:

```text id="x4tq3k"
3n/2 - 2 comparisons
```

For an odd number of elements, the number of comparisons is bounded by:

```text id="q4n5hm"
3(n - 1)/2 comparisons
```

Thus, the number of comparisons is bounded by approximately:

```text id="y6x9bb"
3n/2
```

## Expected Result

The number of comparisons increases approximately linearly with the input size.

The experimental results should remain within the theoretical comparison bound of approximately `3n/2`.

## Conclusion

The Divide and Conquer approach successfully finds both the maximum and minimum elements of an array in **O(n)** time.

By finding the minimum and maximum together, the algorithm performs fewer comparisons than independently finding the minimum and maximum.

The experimental analysis validates that the number of comparisons is bounded by approximately:

```text id="qf7fxy"
3n/2
```

**Time Complexity: O(n)**
