# Strassen Matrix Multiplication

## Overview

This project implements **Strassen's Matrix Multiplication algorithm** using the **Divide and Conquer** approach to multiply two square matrices of size `n × n`.

Strassen's method reduces the number of recursive matrix multiplications from **8 to 7**, making it more efficient than the conventional matrix multiplication method for large matrices.

## Problem Statement

Write a C program to multiply two square matrices of size `n × n` using **Strassen's Matrix Multiplication method**.

The algorithm recursively divides the matrices into four submatrices and uses seven matrix multiplications to calculate the result.

## Approach

The matrices are divided into four equal submatrices:

```text
A = | A11  A12 |
    | A21  A22 |

B = | B11  B12 |
    | B21  B22 |
```

Strassen's method calculates seven products:

```text
P1 = (A11 + A22)(B11 + B22)
P2 = (A21 + A22)B11
P3 = A11(B12 - B22)
P4 = A22(B21 - B11)
P5 = (A11 + A12)B22
P6 = (A21 - A11)(B11 + B12)
P7 = (A12 - A22)(B21 + B22)
```

The four result submatrices are then calculated as:

```text
C11 = P1 + P4 - P5 + P7
C12 = P3 + P5
C21 = P2 + P4
C22 = P1 - P2 + P3 + P6
```

Finally, the four submatrices are combined to obtain the resultant matrix `C`.

The following operations are implemented:

## Time Complexity

The recurrence relation for Strassen's algorithm is:

```text
T(n) = 7T(n/2) + O(n²)
```

Using the Master Theorem:

```text
T(n) = O(n^log₂7)
```

Since:

```text
log₂7 ≈ 2.807
```

the time complexity is:

```text
O(n^2.807)
```

This is better asymptotically than conventional matrix multiplication:

```text
O(n³)
```

## Space Complexity

The algorithm requires additional memory for submatrices, temporary matrices, and recursive calls.

The auxiliary space requirement is approximately:

```text
O(n²)
```

apart from recursion-related overhead.

## Expected Result

Strassen's algorithm should produce the same matrix multiplication result as the conventional method.

For larger matrices, its lower asymptotic complexity can provide better performance, although for small matrices the additional matrix addition, subtraction, memory allocation, and recursion overhead may reduce its practical advantage.

## Conclusion

Strassen's Matrix Multiplication successfully multiplies two square matrices using the **Divide and Conquer** technique.

Instead of performing eight recursive matrix multiplications, Strassen's method performs only **seven**, reducing the overall time complexity from:

```text
O(n³)
```

to:

```text
O(n^2.807)
```

Thus, Strassen's algorithm is particularly useful for multiplying large square matrices.

**Time Complexity: O(n^2.807)**
**Space Complexity: O(n²)**
